# Cabinet modules

Предварительные доменные границы кабинета:

- `dashboard`
- `capital`
- `earn`
- `strategies`
- `events`
- `transactions`
- `reports`
- `notifications`
- `profile`
- `settings`
- `support`

Каждый модуль в дальнейшем получает собственные `pages`, `components`, `api`, `model` и `routes` по мере появления бизнес-логики.
