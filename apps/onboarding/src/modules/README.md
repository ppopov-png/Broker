# Onboarding modules

Планируемые независимые блоки:

- `account` — создание аккаунта;
- `client-type` — физическое/юридическое лицо;
- `kyc` — KYC физлица;
- `kyb` — проверка компании и бенефициаров;
- `funding` — выбор и создание первичного пополнения;
- `activation` — статус активации аккаунта.

Состояние onboarding в дальнейшем определяется сервером, а не только текущим URL браузера.
