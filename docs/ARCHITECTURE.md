# Архитектура Broker 2.0

Broker 2.0 хранится в одном репозитории как npm-workspaces монорепозиторий, но состоит из трёх независимых frontend-приложений.

```text
apps/
├── site/
├── onboarding/
└── cabinet/

packages/
├── ui/
├── brand/
├── shared/
└── api/
```

## Границы

### site
Публичный маркетинговый сайт. Не содержит KYC, балансы, портфель и другую приватную бизнес-логику.

### onboarding
Самостоятельное приложение для пути до активного аккаунта: выбор типа клиента, регистрация, KYC/KYB, первичное пополнение и статус активации.

### cabinet
Авторизованный продуктовый интерфейс. Внутри функциональность разделяется на доменные модули (`capital`, `earn`, `strategies`, `events`, `transactions`, `reports` и т.д.).

### packages
Только общая инфраструктура. Бизнес-модули одного приложения не импортируются другим приложением напрямую.
