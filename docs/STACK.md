# Стек Trigonum Broker

## Базовый

- TypeScript + React 19 — UI и типизация доменных моделей.
- Vite — dev-сервер и production-сборка; запуск через `npm run dev`.
- React Router — маршруты кабинетов и ограничение интерфейса по ролям.
- TanStack Query — запросы к будущему API, кэш, загрузка и инвалидация данных.
- Tailwind CSS 4 — стили и будущие дизайн-токены.
- Lucide React — единый набор интерфейсных иконок.
- Recharts — графики портфеля и отчётности.
- `clsx` + `tailwind-merge` — безопасная композиция классов компонентов.

## Принципы

- API не вызывается напрямую из компонентов: доступ идёт через `src/shared/api` и feature-хуки.
- В UI не дублируются права: сервер определяет доступ, фронтенд скрывает недоступные действия для ясности интерфейса.
- В проекте только TypeScript (`.ts` / `.tsx`) для нового кода.
- Broker хранит инвестиционные агрегаты, операции и отчёты; не отображает торговые ордера или сделки.

## Команды

```bash
npm run dev      # локальная разработка
npm run build    # проверка TypeScript и production-сборка
npm run preview  # просмотр production-сборки
```
