# Onboarding flows

## Individual

Registration -> email confirmation -> identity verification -> self-certification -> agreements -> enhanced due diligence questionnaire -> review -> approval.

The EDD questions are the individual questionnaire itself. There is no separate questionnaire-file upload step.

## Company

Registration -> email confirmation -> authorised signatory verification -> agreements -> corporate dossier -> enhanced company review -> review -> approval.

A company does not pass the individual self-certification questionnaire.
